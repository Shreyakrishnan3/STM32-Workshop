# STM32H755 Dual-Core: Physical LED Blinking via Timer PWM

This repository contains the firmware configuration to visually blink a physical LED connected to pin **PE9** on an **STM32H755ZI-Q** development board (ARM Cortex-M7 Core).

---

## 📌 Hardware Configuration

The target pin is configured to utilize hardware timer-driven pulse generation instead of standard software toggling:

* **Target Pin:** `PE9`
* **Peripheral Mode:** `TIM1_CH1` (Timer 1, Channel 1)
* **Configuration:** PWM Generation Mode 1
* **Timer Prescaler:** `63`
* **Timer Period (ARR):** `999`

---

## 💻 Implementation Details

In the template code generated by STM32CubeMX, the system sets a continuous 50% duty cycle which refreshes too fast for the human eye to perceive as blinking (causing the LED to appear steadily dimmed). 

To achieve a visible blinking pattern, processing delays are introduced into the execution loop to switch the pulse value between fully ON (half-brightness duty value of `500`) and fully OFF (`0`) at **500ms intervals**.

### Code Snippet (`main.c` Infinite Loop)

```c
  /* Infinite loop */
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    // 1. Set PWM duty cycle to 500 (LED Turns ON)
    __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 500);
    HAL_Delay(500); // Maintain state for 500 milliseconds

    // 2. Set PWM duty cycle to 0 (LED Turns OFF)
    __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 0);
    HAL_Delay(500); // Maintain state for 500 milliseconds

    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
  }
  /* USER CODE END 3 */
```

## 🚀 How to Run the Project

1. Open the project inside **STM32CubeIDE**.
2. Select the **Cortex-M7** application project context.
3. Replace the inner contents of the `while(1)` loop in your `main.c` file with the snippet above.
4. Click **Build Project** (Hammer icon) to compile.
5. Connect your STM32H755ZI-Q board to your computer using the onboard ST-LINK debugger port.
6. Click **Run** (Play icon) to flash the code onto the micro-controller and view the blinking effect.
